# packages/pages — Reference Archive

This directory contains the **original standalone HTML reference pages** created during Velora's early development.

## Status: Legacy Archive

These pages have been **superseded** by:

| Legacy location | Current location |
|---|---|
| Component demos | [`apps/showcase/pages/`](../../apps/showcase/pages/) |
| Copy-paste components | [`packages/velora-components/`](../velora-components/) |
| Documentation | [`apps/docs/`](../../apps/docs/) |

## Why it still exists

- Historical reference — shows the original design explorations
- Contains thematic variants (`velora_noir/`, `velora_earth_tech/`) used as design references
- Backup copies in `backup/` and `screens/` are snapshot archives

## Do not use these pages as templates

These pages may reference older token names or patterns that have been updated in `@velora/css`. 
Always use `apps/showcase` pages or `packages/velora-components` as the authoritative source.

## Safe to archive

This directory can be safely archived or removed in a future cleanup pass once all useful patterns
have been migrated to the showcase or component library.
