Kinetic
Motion

Motion in the framework is engineered for the Technical Aesthete. We reject heavy libraries in favor of "Zero JS" execution, leveraging GPU-accelerated CSS features like Scroll-Timeline and View-Transitions for a browser-native performance profile.

Cinematic Easing

Every transition follows our proprietary mathematical curve: cubic-bezier(0.2, 0.8, 0.2, 1). This ensures a rapid onset with a long, architectural deceleration that mimics high-end camera gimbal movements.

Entrance Velocity 0.82 m/s
Exit Deceleration Linear Logarithmic

Motion Primitives

Reveal-3D

A subtle depth-based entrance animation using CSS 3D transforms to simulate physical lens focus shifts.

Scroll-Driven Sequencing

Leveraging the Scroll-Timeline API to bind element transformations directly to the user's scroll progress.

MPA View Transitions

Native cross-document transitions that allow elements to morph seamlessly between disparate routes.

Technical Implementation

Standardized motion layers for global consistency.
