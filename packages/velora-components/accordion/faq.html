What is Velora?
Velora is a motion-native CSS framework that delivers premium, cinematic web experiences using zero JavaScript for animations or routing. It harnesses the modern Web Platform — scroll-driven animations, view transitions, and native CSS state — to run entirely on the GPU at 120fps.
How does the accordion work without JavaScript?
The native HTML <details> element manages open/closed state with zero scripting. Adding the same name attribute to a group turns them into an exclusive accordion — the browser closes siblings automatically. Height is animated via ::details-content paired with interpolate-size: allow-keywords from the Velora reset.
What browsers are supported?
Velora targets Chrome 140+ (the 2026 baseline). The core technologies — scroll-timeline, view-timeline, @view-transition, ::details-content, and interpolate-size — are all natively supported. Progressive enhancement is encouraged for features with partial coverage.
Can I use Velora with React or Vue?
Velora's CSS can be loaded in any environment, including React or Vue apps. However, the framework's design philosophy is browser-first: components are authored in semantic HTML with CSS managing all state and animation. This replaces the need for Framer Motion, GSAP, or Locomotive Scroll in most marketing contexts.
Is there a paid or premium tier?
The core framework is open-source. Premium template packs — full landing pages, dashboard scenes, and animated hero sections — will be sold separately. A Visual Builder SaaS is planned for a later phase.
