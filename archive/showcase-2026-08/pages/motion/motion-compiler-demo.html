Velora Motion Compiler

HTML becomes motion grammar.

This page uses compact Velora attributes that are scanned, parsed and converted into static CSS by the experimental compiler.

Enter

Duration and easing from attributes.

The compiler reads duration, easing and delay from the attribute value.

vl-enter="fade-up@700ms/ease-out delay:80ms"
Flow

Named presets map to keyframes.

Presets resolve to existing Velora CSS keyframes without a JS runtime.

vl-enter="flow-in@900ms/ease-out delay:160ms"
Loop

Ambient motion can be generated too.

Loop effects are generated as static CSS declarations.

vl-loop-effect="float@3s/ease-in-out"
