O que é o Velora?
Um design system em camadas (@layer) com tokens em oklch, componentes de marketing e motion nativa — pensado para sites premium e documentação pública.
Como testo View Transitions?
Escolha um preset VT na barra, depois abra Sobre e volte: a navegação MPA usa a API nativa, sem SPA.
Preciso de JavaScript para animar?
Não para o núcleo: acordeão, scroll reveals e transições de vista são CSS. O playground usa só um script para tema e presets persistidos em localStorage.
