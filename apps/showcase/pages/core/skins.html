Skins // complete design-system models

Not a palette. A product DNA.

A Skin coordinates typography, grid, density, geometry, elevation, media treatment, components and motion voice. Change the model; retain the semantic interface and Core behavior.

The boundaryCore decides what happens. Skin decides how it feels.

Showcase combines both layers to prove a real product language—not a themed component list.

Act 02 // Skin Contract

Every model must make the same nine decisions.

Foundation

Type + color

Body, display and mono families; weights, leading, tracking, schemes and contrast.

Composition

Grid + density

Columns, gaps, content width, spatial rhythm and information density.

Language

Geometry + material

Radii, border weight, elevation, blur, surface opacity and component anatomy.

Media

Crop + treatment

Aspect ratios, contrast, saturation and the relationship between image and copy.

Motion

Distance + timing

Duration, travel and easing voice—always inside Core and reduced-motion rules.

Modes

Light + dark

Intentional schemes rather than automated inversion or isolated color swaps.
