3D Coordinate Explorer

The 3D Coordinate Explorer is a live CSS 3D engine for visualizing Cartesian and Spherical vector spaces. It demonstrates how CSS perspective, transform-style: preserve-3d, and axis rotation stack to produce genuine three-dimensional space in the browser — without WebGL.

Velora's 3D motion system is built on this same CSS stack. Understanding how CSS handles the Z-axis and rotational velocity is the foundation for choreographing card flips, depth-based entrance animations, and perspective-aware hover states.

The CSS 3D Stack

Three declarations establish a 3D rendering context:

/* 1. Parent defines perspective depth */
.perspective-container {
  perspective: 1200px;
}

/* 2. Children inherit 3D space */
.scene {
  transform-style: preserve-3d;
}

/* 3. Isometric grid tilt */
.grid-3d {
  transform: rotateX(60deg) rotateZ(-45deg);
}

perspective: 1200px sets the vanishing point distance. Smaller values (e.g. 400px) create aggressive foreshortening suitable for dramatic card effects; larger values (e.g. 2000px) produce a softer, near-orthographic 3D look. The explorer uses 1200px — the Velora standard for spatial interfaces.

Coordinate Systems

The explorer supports two projection systems switchable at runtime:

SystemDescriptionBest For
Cartesian X, Y, Z rectilinear axes — the CSS default Grid layouts, card stacks, UI depth layers
Spherical Radial (ρ), polar (θ), azimuthal (φ) — expressed as CSS rotation chains Orbital motion, globe effects, radial menu reveal

In CSS, Spherical coordinates are expressed as a chain of rotateY(θ) rotateX(φ) translateZ(ρ). The order matters — matrices are not commutative.

Axis Decomposition

Every point in the 3D scene is expressed as three independent plane components:

/* X-Plane — horizontal offset */
transform: translateX(1.042rem);

/* Y-Plane — vertical offset */
transform: translateY(0.000rem);

/* Z-Plane — depth offset */
transform: translateZ(-4.29rem);

/* Combined */
transform: translate3d(1.042rem, 0.000rem, -4.29rem);

Negative Z values push elements away from the viewer (toward the horizon). Positive Z values push elements forward, appearing larger and in front of their siblings. The live vector readout in the explorer shows real-time per-axis values for the active node.

Grid Density Control

The grid base uses a pure CSS repeating background to render the coordinate plane:

.grid-base {
  background-image:
    linear-gradient(to right,  var(--vl-grid-line) 1px, transparent 1px),
    linear-gradient(to bottom, var(--vl-grid-line) 1px, transparent 1px);
  background-size: var(--vl-grid-size, 40px) var(--vl-grid-size, 40px);
}

The Grid Density slider adjusts --vl-grid-size from 16px (fine) to 96px (coarse). This is a runtime CSS custom property update — no repaints, no layout recalculations.

Rotational Velocity

Rotational velocity is expressed in radians per second (RAD/S). In CSS motion, this corresponds to the speed of a rotate3d() animation:

@keyframes orbit {
  from { transform: rotate3d(0, 1, 0, 0deg); }
  to   { transform: rotate3d(0, 1, 0, 360deg); }
}

.orbiting-element {
  animation: orbit calc(2 * 3.14159 / var(--rad-per-second) * 1s) linear infinite;
}

A velocity of 12.4 RAD/S means the element completes approximately 1.97 full rotations per second. The explorer derives this value from the simulated node movement speed as it traverses the coordinate field.
