Velora live example

@layer and container isolation for mixed timelines.

Three scenes — three CSS layers — three container names. Scene A uses the document timeline, Scene B uses view(), and Scene C combines both. Each scene is walled off so its rules and container queries can never bleed into the others.

@layer scene-a · auto @layer scene-b · view() @layer scene-c · auto + view()

Isolation model

@layer scene-a / b / c — cascade is scoped; a rule in scene-b can't override scene-a by accident.

container-name: scene-a / b / c — @container queries only fire inside the exact named container they target.

@layer motion — all @keyframes live in one place; no name collision across scenes.

Scene C · hybrid component

Two timelines on nested elements.

The outer wrapper uses the view timeline for entry. The inner card uses the document timeline for a continuous float. Both run independently without conflict.

vl-scene · container-name: vl-scene

Two timelines, two nesting levels, fully isolated from A and B. Each vl-scene section is its own container so breakpoints are always local.

This is the Velora model: ambient motion, scroll motion, and container-aware layout coexist because each scene is its own CSS layer and container scope.
