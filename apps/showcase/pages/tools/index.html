About the Suite
⬡

Zero-dependency runtime

Every tool runs on the same Velora CSS-only foundation. No animation libraries, no runtime JS bundles — just native CSS scroll-driven animations and the vl-* declarative grammar.

◈

Token-first design

All tools surface the same --vl-* token layer. Changes to the token set propagate instantly across every playground, comparator, and preview.

↺

Copy-ready output

Motion Playground generates valid HTML markup with all active vl-* attributes. Design Playground copies token variable names directly to your clipboard.

⬡

Framework integration

Each tool is cross-linked to the relevant API catalog, documentation, and sibling tools — so you can move fluidly between designing, testing, and referencing without losing context.
