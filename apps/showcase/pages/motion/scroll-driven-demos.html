Stacking Cards

Inspired by stacking-cards demo · .vl-stack-cards / .vl-stack-card

Cards use position: sticky with incrementing top offsets. Each card scales down and dims via a view(block) animation as the next one covers it — pure CSS, no JS.

Scroll Shadows

Inspired by scroll-shadows demo · .vl-scroll-shadows

Edge shadows appear automatically when overflow content exists to scroll to. Uses the background-attachment: local / scroll trick — no JavaScript, no IntersectionObserver, no events.

Vertical (scrollable)

CSS Scroll Shadows — the shadow at the top edge appears only when you have scrolled down. The bottom shadow appears when more content is below.

This uses four background layers: two with background-attachment: local to mask the shadow at the edges, and two with background-attachment: scroll to provide the visible gradient.

Because local layers scroll with the content, they perfectly cover the fixed shadow layers exactly at the scroll boundary — zero JavaScript.

Scroll down to see the top shadow appear. Keep scrolling to see the bottom shadow disappear at the end.

Works in every modern browser. No polyfill needed. Accessible by default — screen readers ignore purely visual shadows.

Tune the shadow size with --vl-scroll-shadow-size.

Shrinking Header

Inspired by shrinking-header-shadow demo · vl-effect="header-shrink"

A fixed/sticky bar that condenses its padding and gains a shadow as the page scrolls. Tied to scroll(root block) with a pixel range so the transition completes in the first 120px of scroll.

Image Reveal

Inspired by image-reveal demo · vl-effect="img-reveal"

A clip-path: inset() animates from an inset state to full bounds as the element enters the viewport — more dimensional than a lateral wipe. Combined with a subtle scale for depth.

🏔
🌊
🌲
<img vl-effect="img-reveal" src="…" alt="…" />

/* The reveal runs as the element enters the viewport */
/* from: clip-path inset(8% 12%) + scale(1.05) + opacity(0.2) */
/* to:   clip-path inset(0) + scale(1) + opacity(1)            */

/* Override the range for tighter / looser timing: */
[vl-effect="img-reveal"] {
  animation-range: entry 0% entry 75%; /* default */
}

Cover Flow

Inspired by cover-flow demo · .vl-cover-flow / .vl-cover-flow__item

Scroll-snapped horizontal carousel. Items entering the visible area animate in from a 3D-tilted state using animation-timeline: view(inline). Odd children tilt left; even children tilt right.

  <figure class="vl-cover-flow__item">…</figure>
</div>

.vl-cover-flow__item { --vl-coverflow-rot: -28deg; }

Rotate on Scroll

Inspired by 3d-shoe-explorer demo · vl-effect="rotate-scroll"

Element rotation is tied to the view timeline — the element spins as it passes through the viewport. Use --vl-rotate-from and --vl-rotate-to to control the range.

⬡

−180° → +180°

◯

0° → 360°

⬜

45° → −45°

2×

0° → 720°

<div vl-effect="rotate-scroll"
     style="--vl-rotate-from:-180deg; --vl-rotate-to:180deg;">
  ⬡
</div>

A lateral clip-path wipe that reveals the element from left to right as it enters the viewport. Distinct from img-reveal which expands from the centre. Range: entry 0% cover 50%.
