# Design documentation

This folder holds **design narrative exports** and static PDFs. Token and motion **implementation** truth lives in `packages/css/src/` (especially `01-tokens.css` and motion layers).

## In this repository

- **[design-system/](../../design-system/)** (repo root) — Markdown design specs and themes (`velora_noir`, `velora_earth_tech`, etc.).
- **[design/assets/](assets/)** — Exported PDFs (brand media kit, design system deck, agent handbook/skill-set PDFs). Prefer editing the Markdown sources under `docs/agents/` and regenerating PDFs when they change.

## Snapshot

The sibling folder [../velora-design-system/](../velora-design-system/) contains HTML previews and PNGs for design review; it is not the runtime showcase (`apps/showcase`).
