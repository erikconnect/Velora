03. Body Variants

BODY_MD / 16PX / MANROPE REGULAR

The standard body variant is designed for high legibility in documentation and interface descriptions. It maintains a 1.6 line-height to ensure comfort during long-form reading sessions.

BODY_SM / 14PX / MANROPE MEDIUM

Small variants are used for metadata, tooltips, and secondary interface elements. We increase the weight to Medium to preserve ink-trap clarity at smaller optical sizes on high-DPI displays.

The Kinetic Voice

Negative Space as Structure: We reject the use of lines to contain thought. Instead, we use varying scales and geometric proximity to create hierarchy. White space is not "empty"—it is the frame.

Extreme Contrast: By pairing massive Display headings with microscopic metadata, we create a tension that feels both technical and luxurious. This "Editorially Brute" style is the core of Velora.
