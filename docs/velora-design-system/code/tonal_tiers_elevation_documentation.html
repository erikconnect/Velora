The Depth Formula

Velora utilizes a constant hue (145°) and chroma (0.01) across all tiers. Depth is achieved solely by incrementing the Lightness value (L) in the OKLCH space. This ensures a consistent "Material Soul" while providing clear functional boundaries.

Cascade Layers & Optimization

Velora's elevation model is optimized for 120fps fluid interaction. By avoiding complex CSS filters and box-shadow calculations, we reduce the Paint and Composite overhead by approximately 45% compared to standard Material Design implementations.

The "Cascade Layer" approach treats every component as a discrete luminosity layer. When an element is focused, we don't move it closer to the user; we simply shift its luminosity profile to the next tier up. This "static-motion" technique prevents layout shifts and maintains pixel-perfect alignment across all resolutions.
