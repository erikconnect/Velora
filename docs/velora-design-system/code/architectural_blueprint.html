The Tonal Stack

Traditional UI relies on shadows to denote depth. Velora utilizes OKLCH-based tonal layering—a perceptually uniform color space that creates depth through luminosity shifts rather than artificial dropshadows.

By nesting surfaces with precise lightness deltas, we achieve a "etched" or "machined" aesthetic. This reduces layout shifts and improves GPU rendering efficiency by eliminating complex shadow calculations.

"Depth is not a shadow; it is the relationship between materials."
